Crypto Licensing Deadlines Worldwide

One row per jurisdiction (regulator, regime, status, next or last key date, official register) and one row per dated event (law adopted, application window, transition end, ban), each linked to the law or regulator notice it comes from.

Brazil: Crypto Platforms and Central Bank (BCB) Authorisation Status

Data Dictionary: Global Deadlines

jurisdictions.csv

FieldDescription
jurisdiction_codeISO 3166-1 alpha-2 code in lower case (eu = EU-wide regime)
jurisdictionName in English
regionRegion used for filtering on the map
regulatorCompetent authority
regimeLicensing regime or law
statusupcoming (a key date is ahead), date_pending (regime adopted, date not set) or in_force
next_or_last_key_dateISO date of the next key date, or the last one if the regime is in force
event_typeType of that key date (see deadlines.csv)
days_left_at_buildDays from the build date to the key date (blank if none)
pending_noteWhat is still pending, when no date is set
official_register_urlRegulator's public register of licensed firms
register_formatFormat of that register (HTML, CSV, API, PDF)
source_urlsOfficial sources for the key date, separated by “ | ”
page_urlJurisdiction page on vasptracker.com

deadlines.csv

FieldDescription
jurisdiction_code, jurisdiction, regulator, regimeAs in jurisdictions.csv
dateISO date of the event
event_typelaw_adopted, promulgated, assent, in_force, regime_start, effective_date, rules, window_opens, application_deadline, deadline_extended, transition_end, cutoff, ban, licences, notice, consultation_end, pilot_end, bill, veto_upheld
key_dateTrue if this is a date firms must act on
our_calculationTrue if the date is computed by us from the rule's text, not stated by the regulator
description_enWhat happens on that date
source_typeHighest-ranked source type: official, company or press
source_urls / source_typesAll sources and their types, separated by “ | ”
page_urlJurisdiction page on vasptracker.com

deadlines.json

FieldDescription
license, attribution, generated_atLicence and build metadata
source_hierarchyOrder in which source types are trusted
jurisdictions / eventsSame rows as jurisdictions.csv and deadlines.csv

UTF-8, comma-separated. Multi-value fields use “ | ” (global) or “; ” (Brazil). Data comes from official sources first; each row carries its source URLs and source type.
